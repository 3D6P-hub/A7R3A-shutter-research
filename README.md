# Sony A7R3A (ILCE-7RM3A) 电子快门声音研究

> ⚠️ **高风险警告**：本项目涉及相机固件修改。**错误的闪存写入会导致相机变砖（无法开机），需专业维修。**
> 作者已在研究中因固化选洞失误导致一台 A7R3A 软砖（见 `docs/变砖复盘与杜绝指南.md`）。
> **普通用户请勿尝试任何闪存写入。** 仅供安全研究学习。

## 项目目标
让 Sony A7R3A 的电子（静音）快门发出自定义声音（类似 Sony A1 / A7M4 的快门声），
并研究 CXD90045 "Astra" BIONZ X 平台的声音机制。

## 🔬 核心发现（详见 docs/）
- 声音机制：beeplist 按 kindId 注册样本，PIN 音（kind 1-7）经 CP `SendSysSndPin`；
  静音模式抑制 kind {1,2,3,7}，kind 4/5/6/8 不抑制。
- AP 把 ObjMsg 0x1000 槽值直接当 kindId（非 soundId→kindId 查表）。
- **变砖根因**：`TsOtOS_2_init` 是 .dynsym 导出函数，开机被 `dlsym` 按名动态调用，
  静态零引用扫描漏判 → 误选为洞 → 开机崩溃。
- **libObj.so 无安全代码洞**：.text 密集无缝，.rodata 零块是被引用的数据。
