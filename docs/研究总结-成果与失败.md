## 二、成果（成功的）✅

1. **固件完整提取**：17 分区 dump + SHA 校验，libObj.so / av-cam.bin / 30 个声音素材。
2. **声音架构全摸清**：
   - beeplist 按 kindId 注册样本（合法域 1..9）；
   - PIN 音（kind 1-7）经 CP `SendSysSndPin`，APP 音（kind 0）经 AP；
   - f0 块浮点音频格式：32B/帧 = 1B 指数 + 31 int8 样本，`sample=q<<shift`，24kHz。
3. **AP 发声协议破解**：ObjMsg(cate 0x3410, mid 0x1120) + ParamStd + AddParam(0x1000) + IssueCommandAsync；**PLT 是 ARM 模式须 blx**。
4. **CP 触发链全摸清**：state_compute→exposure_event_handler→dispatcher→handler 表→KASHA3_play→SendSysSndPin。
5. **静音压制机制精确解释**：kind∈{1,2,3,7} 携带模式参数被 DSP 压制；kind 4/5/6/8+ 填 -1/-1 哨兵（无门控能响）。
6. **kindId 重定向实证**：kind4 音频→KASHA，实机确证对焦时响。
7. **M1 RAM 注入成功**：电子快门 kind8 发声链路跑通（17:30 里程碑）。
8. **f0 音频编码器**：WAV→24k→f0，round-trip 完美（max_err=0）。
9. **方法论沉淀**：固化守则 v1.1、洞区多路扫描、Unicorn 初始化仿真、变砖复盘。

## 三、失败（证否的方向 + 事故）❌

### 证否的技术方向（均已回滚）
| 方向 | 结果 | 原因 |
|---|---|---|
| prio 6→3 | 无效 | priority 是 AP 仲裁字段，CP/DSP 静音门不看它 |
| mode 检查 / 准入绕过 | 无效 | 非静音根因 |
| 条件 cave 读 [r5+0xd5] 区分对焦/快门 | 失败 | setup 在 cave 前改写 [0xd5] |
| cat8→cat0 / cat8 flag / NOP kind3 | 电子无声 | 电子不进 dispatcher |
| KASHA 门控 NOP | **开机连续响！** | 门控防连续播放，盲 NOP 破坏（紧急回滚） |
| default 路径加 SendSysSndPin(4) | 无声 | 电子曝光走独立 EC 路径，不调该函数 |
| 音量提升（getter 补丁） | 无效 | 音量启动时从 BK4 缓存，运行时改 getter 无用 |

### 重大事故：M5 固化变砖
- **经过**：把 AP hook 写进 libObj 闪存，选 `TsOtOS_2_init@0x53cf5a` 作洞（静态零引用判死代码）。
- **根因**：该函数是 **.dynsym 导出函数**，开机被 `dlsym("TsOtOS_2_init")` 按名动态调用——静态地址扫描查不到名字调用 → 漏判 → 开机执行 stub → im.elf 挂起 → 软砖。
- **后果**：相机卡拍摄界面（仅 M）/重启循环，USB 服务模式起不来。

### 软件救援全失败
| 方法 | 结果 |
|---|---|
| 大容量模式捕捉 | 0D99/0336 根本不出现（im.elf 挂起前未启用 USB gadget） |
| 直通服务模式（StartSenser vendor 请求） | 相机固件 STALL 拒绝（三种驱动一致 I/O / Pipe error） |
| 按键组合强制服务/更新模式 | A7R3A 无 documented 组合，无效 |
| SD 卡触发 | 固件无 SD 救援触发（更新标记全在内部 /setting） |

### 离线分析结论
- **libObj.so 无安全代码洞**：.text 100% 密集无缝；.rodata 零块是被引用的数据缓冲。
- Unicorn 实证：TsOtOS_2_init 不在 .init_array（外部 dlsym 调用）；候选零区初始化不执行但是数据区，仍不安全。

## 四、教训（沉淀为守则 v1.1）

1. **静态零引用 ≠ 死代码**：导出函数会被 dlsym 按名动态调用，_init 函数经自定义初始化表调用。
2. **固化前必须模拟器跑 boot 动态验证**洞区不被执行（静态扫描只是初筛）。
3. **RAM 注入零风险优先**（不落盘、拔电池即恢复）。
4. **固化前确认回滚通道在线可连**（砖机态 USB 起不来则回滚无门）。
5. **分步固化**：写一处→冷启动验证→再写下一处。
6. **单分区原则**：只改 n15/n3，绝不碰启动链 n5/n7 与引导头 0x2C000。
7. **死洞首选纯零填充区**，绝不选函数体（尤其 _init / 导出函数）。
